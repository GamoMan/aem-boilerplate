## Installation
To use the Gemini CLI tools, ensure you have the necessary dependencies installed.

```sh
# Example: Install Gemini CLI (if it were a separate package)
# npm install -g @google-gemini/cli
```

## Local development
1. Ensure the Gemini CLI is installed and configured.
2. Run relevant Gemini CLI commands from the project root.

```sh
# Example: Run a Gemini command
# gemini analyze .
```
